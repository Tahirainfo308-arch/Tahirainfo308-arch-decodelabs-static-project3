The Universal Law

Input → Process → Output

Every interactive element on the web follows the IPO loop. Understand this, and you understand all of frontend engineering.

01
🖱️

Input

A requirement from the environment — a user click, keypress, or page load event.

02
⚙️

Process

The system detects the signal and applies business logic — your JavaScript function runs.

03
✨

Output

A visible change — the DOM is mutated and the environment dynamically updates.

Variable Integrity

Signaling Intent

Choosing the right variable declaration signals your intent to the team and prevents bugs before they happen.

Declaration Reassignment Scope Modern Usage When to Use
const No Block ✓ Preferred DOM references, fixed values — default choice
let Yes Block ✓ When needed Counters, flags, any value that must mutate
var Yes Function ✕ Avoid Legacy code only — prone to hoisting bugs
